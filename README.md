# Firecom Servicemonitor

[Open de webapp](https://fpvarabic.github.io/firecom-monitor/)

Klik op **Verbinden met werkruimte**, meld je aan in het privévenster en bevestig de verbinding. Houd het privévenster open tijdens het werken.
